# AI Prompt for Expanding Obsidian Hills Scenario Database

## Copy and paste this prompt to any AI to generate more content:

---

You are helping expand a scenario database for "Obsidian Hills," a post-apocalyptic survival community set in the Nevada high desert. The community of 180 survivors lives in a converted Old West theme park, 23 days after a zombie-like outbreak collapsed civilization.

**WORLD CONTEXT:**
- 180 survivors in fortified Old West theme park
- Nevada high desert setting (extreme temperatures, low water)
- Infected are fast, aggressive, spread through bites
- Resources are scarce, every mission is dangerous
- Community has horses, limited fuel, solar power, radio contact
- Nearby locations include ranches, truck stops, abandoned towns

**CURRENT [CATEGORY] ENTRIES:** 
[Paste the current contents of whichever .txt file you want to expand]

**TASK:** Generate 15 new [CATEGORY] entries that:
1. Fit the established world tone and setting
2. Vary in severity and type  
3. Are specific enough to create interesting scenarios
4. Match the format and style of existing entries
5. Don't repeat existing concepts

**CATEGORIES:**
- **Objectives:** Mission types (what the team is trying to accomplish)
- **Locations:** Places to visit (include distance/direction if outside sanctuary)
- **Challenges:** Primary obstacles/threats during missions
- **Complications:** Additional problems that make missions harder
- **Opportunities:** Positive discoveries and advantages

**OUTPUT:** List the 15 new entries in the same format as the existing file, one per line.

---

## How to Use:
1. Choose which category you want to expand (objectives, locations, challenges, complications, opportunities)
2. Replace [CATEGORY] with your chosen category name
3. Copy the current contents of that .txt file and paste where it says [Paste the current contents...]
4. Send to AI (ChatGPT, Claude, etc.)
5. Copy the results and add them to your .txt file in GitHub

## Example Usage:
"Generate 15 new **challenges** entries..." then paste your current challenges.txt content.

The AI will generate entries that fit your world's tone and don't duplicate what you already have.
